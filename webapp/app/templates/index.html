How to Use

  1. Upload your PDF file
  2. Enter your PaddleOCR API token
  3. Optional: Enter book title and author
  4. Select TOC generation options
  5. Click "Convert to EPUB"
  6. Download the generated EPUB file

About

This tool converts PDF files to EPUB format using PaddleOCR API for layout analysis and text extraction. It supports intelligent chapter detection and generates well-formatted EPUB files suitable for e-readers.
